# Higanbana: published data

This branch holds the public data files for [Higanbana](https://github.com/Raikennnnn/Higanbana).
It is updated automatically by the daily
[DShield live feed workflow](https://github.com/Raikennnnn/Higanbana/blob/main/.github/workflows/dshield-live.yml).
There is no code here.

| File | Contents |
|---|---|
| `dshield/summary.json` | Daily aggregates: SSH attack volume (30 days), most attacked ports, username ranking |
